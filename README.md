# 💍 Wedding Planner — From Planning to Creating Your Dream Wedding

A modern wedding planning web application designed to bring all the important aspects of wedding preparation into one organized platform. From planning events and managing guests to keeping track of wedding details, the application aims to make the entire wedding-planning experience simpler and more enjoyable.

## ✨ Features

* 💒 **Wedding Planning** — Organize important wedding activities and requirements in one place.
* 📅 **Event Planning** — Keep track of different ceremonies, functions, and important dates.
* 👥 **Guest Management** — Organize and manage your wedding guest information.
* 💰 **Budget Management** — Keep track of wedding-related expenses and planned spending.
* 📋 **Task Management** — Organize tasks and monitor planning progress.
* 🎨 **Modern User Interface** — Clean and responsive interface designed for an intuitive user experience.
* 📱 **Responsive Design** — Works across desktop, tablet, and mobile screen sizes.

## 🛠️ Tech Stack

The project is built using modern web development technologies.

* **Frontend:** React / JavaScript
* **Styling:** CSS / Tailwind CSS
* **Backend:** Node.js / Express.js
* **Database:** MongoDB
* **Authentication:** OAuth

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### 1. Clone the repository

```bash
git clone https://github.com/AdiDev8928/Wedding-Planner-From-planning-to-creating-your-dream-wedding.git
```

### 2. Navigate to the project

```bash
cd Wedding-Planner-From-planning-to-creating-your-dream-wedding
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

If the application requires environment variables, create a `.env` file in the project root and add the required configuration.

Example:

```env
API_KEY=your_api_key
DATABASE_URL=your_database_url
```

Do not commit sensitive credentials or API keys to GitHub.

### 5. Start the development server

```bash
npm run dev
```

The application should now be available at the local development URL shown in your terminal.

## 🎯 Project Goal

Wedding planning often involves managing many different pieces of information at the same time—events, guests, tasks, budgets, vendors, and deadlines.

The goal of this project is to provide a centralized digital platform where these details can be organized and managed efficiently, reducing the need to rely on scattered notes, spreadsheets, and multiple applications.
